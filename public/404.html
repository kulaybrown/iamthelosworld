Jumpy Run

Jumpy Run is a 2D pixel endless runner game hosted on IAMTHELOSWORLD. Players control a runner dodging obstacles, collecting items, and striving for high scores.

Why Jumpy Run uses Google Sign-In:
  • Authenticate your player profile securely
  • Save and sync high scores across sessions
  • Display your username on the global Jumpy Run leaderboard
